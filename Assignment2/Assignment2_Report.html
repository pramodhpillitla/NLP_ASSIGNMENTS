1. Executive Summary & Problem Formulation

Conversational commerce is transitioning from brittle rule-based decision trees to autonomous, tool-augmented AI agents. In retail and e-commerce environments, standard standalone LLMs fail catastrophically because they cannot: (1) access real-time stock levels, (2) perform exact arithmetic for discounts and sales taxes, (3) execute transactional database modifications safely, or (4) adhere to strict contractual customer service policies.

This assignment designs, implements, and evaluates an autonomous Multi-Agent Cognitive Architecture tailored for end-to-end e-commerce workflows. By integrating the ReAct (Reasoning and Acting) paradigm with function calling and deterministic SQL tool execution, the system automates product discovery, personalized recommendations, inventory-guarded cart management, dynamic discount application, transactional checkout, and post-purchase logistics tracking.

2. Agentic Framework & Cognitive Architecture

2.1 The ReAct (Reasoning + Acting) Paradigm

Standard prompt-response models attempt to generate final answers in a single unconstrained autoregressive forward pass. Under the ReAct pattern (Yao et al., 2022), the agent alternates between verbal reasoning steps ('Thought') and structured environmental interactions ('Action' / 'Observation'):

Thought: User asks for a lightweight laptop under $1000. I need to query the database with category='Electronics' and price <= 1000.
Action: search_products(query='lightweight', category='Electronics', max_price=1000)
Observation: [{'name': 'UltraBook Pro 14', 'price': 949.99, 'rating': 4.8, 'stock': 25}]
Thought: Found matching product within budget and in stock. Formulating recommendation response.
Final Response: Recommending UltraBook Pro 14 at $949.99...

2.2 Multi-Agent Specialization & Role Decomposition

To maintain clean architectural boundaries and prevent cognitive overload, the system decomposes e-commerce workflows into specialized sub-agents managed by a central Orchestrator:

  • Supervisor / Orchestrator Agent: Classifies user intent, maintains cross-turn session memory, and dispatches sub-tasks to domain agents.
  • Product Discovery & Recommendation Agent: Conducts multi-attribute SQL search (category, budget, customer rating, semantic keywords).
  • Cart & Pricing Agent: Maintains shopping cart state, verifies stock availability, applies validated promo coupons, and computes sales tax.
  • Checkout & Transaction Agent: Executes transactions, updates database records, and generates verified order confirmation numbers.
  • Logistics & Order Tracking Agent: Queries shipping carriers (FedEx, DHL, UPS) for active delivery waybills and status updates.
  • Customer Policy Agent: Retrieves store terms, warranty periods, and return policies using context grounding.

    5. Safety Guardrails & Deterministic Pricing Analysis

    A paramount danger in deploying generative AI in commerce is 'price hallucination' or unauthorized checkout discounts. In our architecture:

  • Deterministic Math Engine: The LLM never calculates order totals directly in text; all calculations are executed by deterministic Python/SQL functions.
  • Inventory Concurrency Lock: Orders cannot be finalized if requested quantity exceeds current inventory stock in the relational database.
  • Coupon Authorization Gate: Coupon codes must match active database records and satisfy minimum order thresholds (e.g. FESTIVE20 requires >= $200).
